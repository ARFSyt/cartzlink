# CARTZ Link changes

- Replaced the single Last connected card with a recent-domain dropdown in the ERP Host field.
- Every successfully loaded ERP host is stored locally, de-duplicated, newest first, maximum 20.
- Changed Android WebAuthn from `forBrowser` to crash-safe `forApp`.
- Arbitrary-domain browser WebAuthn requires privileged-browser trust from the credential provider; `forApp` instead uses Android Digital Asset Links for each participating ERP domain.
- Existing WebView loading progress bar remains unchanged.
